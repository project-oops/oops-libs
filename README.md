# oops-libs

**Shared Host-Side Rust Libraries for the OOPS Ecosystem.**

`oops-libs` is the collection of shared, lightweight Rust crates used by all host-side tools in the OOPS collection ([Prosperous](../prosperous/), [SELFish](../selfish/), [Orbistoun](../orbistoun/), and `obscene-tool`). It unifies build stamps, logging, shared application paths, and embedded documentation without pulling heavy runtime dependencies into simple CLI tools.

## Role in THE LOOP

Within the [OOPS ecosystem](../docs/THE_LOOP.md), `oops-libs` provides the **Unified Host Infrastructure**:

```
┌───────────────────────────────────────────────────────────┐
│ oops-paths: One Directory, Shared                         │
│ Windows: %APPDATA%\OOPS\      Linux: ~/.local/share/OOPS/ │
└─────────────────────────────┬─────────────────────────────┘
                              │
       ┌──────────────────────┼──────────────────────┐
       ▼                      ▼                      ▼
  Prosperous              Orbistoun              obSCEne
  (Target Registry       (Save Overlays &       (Hardware
   & Credentials)         Mounted Titles)        Sweep Reports)
```

1. **One Directory, Shared**: Target registrations configured in `pros`, save directories mounted in `orbistoun`, and hardware reports generated by `obscene` all share `%APPDATA%\OOPS\`. No tool has to learn another tool's private paths.
2. **Deterministic Build Stamps (`oops-build`)**: Every tool binary stamps its exact git commit and build timestamp with zero runtime dependencies.
3. **Unified Logging (`oops-log`)**: Standardizes console and file logging facades across all CLI and GUI utilities.

## Developer Quickstart

### 1. Build and Run Tests
```bash
./bin/oops-libs check    # formatting, clippy at -D warnings, unit tests
```

### 2. Using in Sibling Crates
In your host tool's `Cargo.toml`:

```toml
[dependencies]
oops-build = { path = "../../oops-libs/crates/oops-build" }
oops-log   = { path = "../../oops-libs/crates/oops-log" }
oops-paths = { path = "../../oops-libs/crates/oops-paths" }

[build-dependencies]
oops-build = { path = "../../oops-libs/crates/oops-build" }
```

## Crates Overview

| Crate | Purpose | Dependencies |
|---|---|---|
| **`oops-build`** | Generates build-time metadata (git commit, build timestamp, dirty state). | None |
| **`oops-log`** | Configures `tracing` subscribers with optional file and OTLP output features. | `tracing`, `tracing-subscriber` |
| **`oops-paths`** | Canonical platform paths for config, cache, logs, and portable mode (`PORTABLE.txt`). | `dirs` (`platform-dirs` feature, on by default) |
| **`oops-docs`** | In-app Markdown documentation viewer and embedded egui window. | `egui`, `pulldown-cmark` |
